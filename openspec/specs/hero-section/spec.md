# hero-section Specification

## Purpose

定义首屏 Hero 区域的展示行为：全屏布局、视觉层叠（CSS 渐变底 + Canvas 静态粒子）、居中展示个人品牌信息，并在亮/暗两种主题下正确呈现。该能力是站点内容展示的技术起点，后续其余 Section 将复用其背景与主题约定。

## Requirements

### Requirement: 全屏布局与居中内容

Hero Section SHALL 占满浏览器视口高度（100vh，移动端不低于合理可用区域），并 SHALL 在视口中垂直水平居中展示以下三段内容：访客的姓名、职业、一句话介绍。姓名与职业作为独立文本行展示，一句话介绍位于其下方。

#### Scenario: 桌面视口正常展示

- **WHEN** 用户在桌面浏览器打开站点首页
- **THEN** Hero 区域占满首屏视口高度，姓名、职业、一句话介绍在视口内垂直水平居中显示

#### Scenario: 极小视口内容不被裁剪

- **WHEN** 视口高度小于内容自然高度（如横屏低高度窗口）
- **THEN** Hero 区域保持 100vh 最小高度，超出部分自然溢出且页面可滚动，内容不因裁剪而不可读

### Requirement: CSS 渐变背景层

Hero Section SHALL 以线性 CSS 渐变作为最底层背景，明亮与暗黑模式下各自呈现对应的配色方案。

#### Scenario: 两种模式下的渐变呈现

- **WHEN** 页面处于明亮模式或暗黑模式
- **THEN** Hero 背景为各自模式对应的线性 CSS 渐变，切换模式后渐变配色随模式变化

### Requirement: Canvas 静态粒子层

Hero Section SHALL 在渐变背景之上叠加一层 Canvas 绘制的静态粒子（星点），Canvas SHALL 仅在初始化、视口尺寸变化与主题模式变化三种时机各绘制一次，不注册逐帧动画循环。

#### Scenario: 初始化渲染一次

- **WHEN** Hero Section 首次挂载
- **THEN** Canvas 按视口尺寸绘制一次固定分布的星点粒子，此后直至视口尺寸变化或主题模式变化不重绘、不产生逐帧动画

#### Scenario: 视口尺寸变化重绘一次

- **WHEN** 浏览器窗口尺寸发生变化
- **THEN** Canvas 以当前视口尺寸重新绘制一次粒子分布（防抖后执行），仍无逐帧动画

#### Scenario: Canvas 不可用降级

- **WHEN** 浏览器不支持或初始化 Canvas 2D context 失败
- **THEN** 页面不报错，Hero 仅显示 CSS 渐变背景（静默降级），姓名/职业/介绍内容不受影响

### Requirement: 个人信息文案占位

Hero Section 展示的姓名、职业、一句话介绍 SHALL 来源于站点的内容配置常量。本变更交付时使用占位文案，后续由站点所有者替换为真实内容，且不改变展示行为。

#### Scenario: 使用占位内容展示

- **WHEN** 使用默认内容配置构建站点
- **THEN** Hero 展示占位的姓名、职业与一句话介绍，无空文本或渲染错误

#### Scenario: 替换真实内容

- **WHEN** 内容配置常量被替换为真实姓名、职业、介绍
- **THEN** Hero 直接展示新文案，无需修改 Hero 组件逻辑

### Requirement: 行动号召按钮

Hero SHALL 在既有三段内容（姓名、职业、一句话介绍）下方呈现一个行动号召按钮，按钮文案为「查看我的项目」。点击该按钮 SHALL 平滑滚动到项目 section（锚点 `#projects`），滚动与顶部偏移行为与全站锚点导航约定一致。按钮 SHALL 使用固定位置可访问的锚点链接实现（不依赖 JS）。按钮配色 SHALL 随亮暗模式自适配且与 Hero 现有配色协调；按钮的出现 SHALL 不改变既有三段内容的居中布局与 Hero 的全屏高度行为。

#### Scenario: 点击 CTA 滚动到项目区

- **WHEN** 用户点击 Hero 的「查看我的项目」按钮
- **THEN** 视口平滑滚动到项目 section，其内容顶部露出导航栏高度的偏移间距、标题完整可见

#### Scenario: 按钮亮暗自适配

- **WHEN** 用户切换主题模式
- **THEN** CTA 按钮在两种模式下均保持可读对比度、无残留反色

#### Scenario: Hero 布局与非目标行为不变

- **WHEN** 以默认内容构建并对比归档主 spec 的既有行为
- **THEN** 姓名职业与一句话介绍仍居中展示、背景渐变与粒子、100vh 行为均无差异，仅新增按钮元素
